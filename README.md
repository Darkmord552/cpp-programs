# C++ Programs

Kolekcja moich programów i projektów napisanych w języku C++.

## Zawartość repozytorium

* **`System-Oceniania/`** – Konsolowy program do obliczania średniej ocen ucznia oraz wyznaczania oceny opisowej.
* **`Zliczanie_towaru/`** – Program zlicza towar dostarczony w dostawach.
* **`Obliczanie_NWD/`** – Konsolowy program oblicza największy wspólny dzielnik podanych liczb przez użytkownika.
